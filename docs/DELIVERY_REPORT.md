Extraction: `server/scripts/law/pdf_to_text.py` reads the PDF's own text layer (repairs the lam-alef and Allah ligatures stored in reverse order,
drops footnotes and page numbers, restores heading numbers). `مدونة الشغل` has a scrambled text layer, so it is read by OCR (tesseract `ara`).
Texts are marked **under review** in the Library: they are machine-extracted and may carry small typos from the PDF itself (split words, missing
spaces in headings; OCR confuses `،` with `؛`). The official PDF hash and URL are stored with each text.

Validation: every imported article has a non-empty body (a short body is a source repeal marker, `نسخت`, shown as such: CCOM 25, land registration 14, DOC 2).
Heading numbers are repaired where the PDF or OCR garbled them (counted on stderr by the extractor). "Missing numbers" in the table are the
remaining gaps of the extracted sequence: articles that are repealed and printed only as a note in the source, or lines the extractor could not read; they are
listed, not hidden, and the text stays flagged "under review". Re-importing the same file is a no-op; re-importing a corrected file adds/updates articles but
does **not** delete numbers that disappeared (clean the code's articles first, as was done for مدونة الشغل).

**Catalog entries with no imported text** (absent from the UI by design): `ADMIN-COURTS` (law 41.90: adala serves only a "copied/repealed" note, supply the consolidated PDF), `DAHIR-CIVIL-SERVICE` (statut général de la fonction publique, adala folder 655), `FRAMEWORK-SOCIAL` (loi-cadre 09.21 on social protection, adala folder 43, id 464: not fetched), `DECREE-*` other than public procurement, the remaining organic laws (e.g. 02.12 appointments, 27.11, 28.11, 59.11) and international treaties. The judicial-organisation law 38.15 **was** imported (`law-38-15-judicial-organization`, 109 articles). To add any text: put its official PDF in `server/storage/corpus-sources/<SLUG>.pdf`, add an entry to `server/data/law/corpus/sources.json` (slug must exist in the catalog; only `https://adala.justice.gov.ma/` URLs are accepted), run the importer. sgg.gov.ma publishes the Bulletin officiel through a form post, so it could not be fetched automatically.
